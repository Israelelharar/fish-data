# fish-data

נתונים ציבוריים לאפליקציה "דייג חכם". יש כאן רק קובצי נתונים וסקריפטים לעיבוד שלהם, בלי קוד של האפליקציה.

הקבצים מתעדכנים אוטומטית כל שעתיים ומתפרסמים בכתובת https://israelelharar.github.io/fish-data/

| קובץ | מה יש בו | מקור |
|---|---|---|
| `rules.json` | חוקי דיג עם תאריכים | רשות הטבע והגנים, משרד החקלאות |
| `accuracy.json` | בדיקה יומית: התחזית מול המדידות בתחנות | MET Norway (CC BY 4.0), השירות המטאורולוגי |
| `sources.json` | מעקב אחרי שינויים במקורות הרשמיים | — |
| `marine.json` | גלים וטמפרטורת מים (כשיופעל) | E.U. Copernicus Marine Service Information |

המידע לעזרה בלבד, והנוסח הרשמי של הרשויות הוא הקובע.
