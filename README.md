# fish-data

נתונים ציבוריים לאפליקציה "דייג חכם". יש כאן רק קובצי נתונים וסקריפטים לעיבוד שלהם, בלי קוד של האפליקציה.

הקבצים מתעדכנים אוטומטית כל שעתיים ומתפרסמים בכתובת https://israelelharar.github.io/fish-data/

| קובץ | מה יש בו | מקור |
|---|---|---|
| `rules.json` | חוקי דיג עם תאריכים | רשות הטבע והגנים, משרד החקלאות |
| `accuracy.json` | בדיקה יומית: התחזית מול המדידות בתחנות | MET Norway (CC BY 4.0), השירות המטאורולוגי |
| `sources.json` | מעקב אחרי שינויים במקורות הרשמיים | — |
| `marine.json` | גלים וטמפרטורת מים | E.U. Copernicus Marine Service Information |
| `gusts.json` | משבי רוח לכל חוף, 7 ימים | Deutscher Wetterdienst (ICON-EU), ECMWF (CC BY 4.0) |
| `status.json` | מצב כל מקור: מתי הצליח לאחרונה ומה השגיאה | — |

## עמידות בתקלות

- כל הרצה מתחילה מהקבצים שכבר באוויר. אם מקור נכשל, נשאר הקובץ הטוב האחרון שלו.
- כל מקור רץ בנפרד, עם ניסיון חוזר ומגבלת זמן. תקלה באחד לא עוצרת את האחרים.
- משבים: ICON-EU ראשי, ECMWF גיבוי (וגם ארבע מראות ענן של ECMWF).
- Copernicus: אם שם של מאגר משתנה, הסקריפט מחפש לבד את השם החדש בקטלוג.
- תקלה שנמשכת 6 שעות פותחת משימה (Issue) עם הוראות תיקון בעברית, ונסגרת לבד כשהמקור חוזר.
- `keepalive.yml` מונע מ-GitHub לכבות את העדכון אחרי 60 יום בלי פעילות.

המידע לעזרה בלבד, והנוסח הרשמי של הרשויות הוא הקובע.
